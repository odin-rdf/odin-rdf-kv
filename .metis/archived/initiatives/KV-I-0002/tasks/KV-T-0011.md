# Persistent free list and space check, without reuse

## Parent Initiative

[[KV-I-0002]]

## Objective

Write the free list at every commit and load it at open, and add `space_check`, which proves every page is owned exactly once (KV-I-0002 REQ-003, REQ-004, NFR-003, decision D3). Pages are **not** reused yet: the file still grows, but after this task no page goes unaccounted for.

## Acceptance Criteria

- [x] `PAGE_FREELIST` in `types.odin`, and `Free_Record{pgno: u64le, txn_id: u64le}` (16 bytes, asserted) in a new `freelist.odin`.
- [x] `Env.free` holds `ready` (sorted `[dynamic]Pgno`) and `pending` (`[dynamic]Free_Record` ordered by `(txn_id, pgno)`), allocated with `env.allocator`. `Snapshot` gains `freelist_pgno` and `freelist_count`.
- [x] **Commit:**
  - builds the new list from `ready` and unused `loose` pages (tag 0), `pending`, then `freed` plus the previous run's pages (tag `S + 1`);
  - allocates a run of `overflow_pages(16 × n)` by extending the file, and writes it with the dirty pages;
  - sets the meta fields;
  - replaces `Env.free` only after the meta sync, under the writer mutex.
  - An empty list writes `freelist_pgno = freelist_count = 0` and no run.
- [x] **Open:**
  - loads the chosen meta page's list and validates every rule in KV-I-0002 ("Free-list validation at open");
  - records with `txn_id < S` go to `ready` and those tagged `S` to `pending`;
  - a violation returns `Corrupted`;
  - `freelist_pgno = 0` with a non-zero count is `Corrupted`.
  - The meta validation in `meta_read` also checks that the run lies within `last_pgno`.
- [x] **`space_check(txn, allocator)`** in `check.odin`:
  - walks the tree (sharing `tree_check`'s walker);
  - marks the run and every free record, and in a write transaction also `freed`, `loose` and pages taken but not yet used;
  - requires every page in `[2, last_pgno]` to be marked exactly once.
  - It returns `(ok, reason)` like `tree_check`.
- [x] **Tests:**
  - round-trip: the free list after N commits equals the union of every `freed`, and survives a reopen;
  - one test per validation rule, using a hand-edited run (flip a tag, unsort, duplicate a page, point into the run, out of range, bad header, count/size mismatch);
  - `space_check` passes after every commit in `run_model` and in `commit_test`'s multi-commit tests;
  - a KV-I-0001-shaped file (both fields 0) opens;
  - an I/O error in commit leaves `Env.free` unchanged.
- [x] **Deliberate-bug checks:** drop the previous run from the new list, or skip one `freed` page, and `space_check` fails. Swap the tag of a record, and open returns `Corrupted`. Record them here.
- [x] `scripts/test.sh` passes.

## Implementation Notes

### Technical Approach
- The run layout is an overflow run whose value is the record array: `Page_Header{pgno, flags = PAGE_FREELIST, overflow_count = k}`, with records from offset 16 spanning the pages. Reuse `overflow_pages` and a validated read like `overflow_check`, generalised to take the expected flag.
- Build the list by merging three sorted sequences: tag 0 (ready ∪ loose, sorted), `pending` (already sorted), and tag `S + 1` (freed ∪ old run, sorted). Build it in the transaction's arena, and copy it into `Env.free` after publishing.
- Put the loading code in `freelist.odin` and call it from `env_open` after `meta_choose`. On failure, `env_open` must release everything (existing deferred cleanup).
- In this task `page_alloc` still extends the file only, so the free list only grows. That's expected.

### Dependencies
None on KV-T-0010. The tags are written the same whether readers are tracked or not.

### Risk Considerations
- Old meta page semantics: the run from snapshot `S` is freed by `S + 1`, never overwritten by it, because D1 in KV-T-0012 keeps it for one more commit. Get the tag right here (`S + 1`), so that it's right before reuse exists.
- Commit now allocates at commit time. Map-full handling for the run is completed in KV-T-0012 (D6). Here, a failing run allocation returns `Map_Full` and aborts cleanly; add a test.

## Status Updates

### 2026-09-24: implemented

**What was built**
- `kv/types.odin`: `PAGE_FREELIST :: 0x10`.
- `kv/freelist.odin` (new):
  - `Free_Record{pgno: u64le, txn_id: u64le}`, asserted 16 bytes with fields at 0 and 8.
  - `Free_State{ready: [dynamic]Pgno, pending: [dynamic]Free_Record}` and `freelist_run_pages(page_size, count)`.
  - `freelist_run`: the one validated reader of a committed run. It checks the run's page is in `[2, last_pgno]`, `count` is in `[1, last_pgno]`, and the header, then returns the records as a slice into the map.
  - `freelist_load`: every validation rule, then the split into `ready` (tag `< S`) and `pending` (tag `S`).
  - `freelist_build`: the next state for a commit.
  - `freelist_write`: serializes a state into the run buffer.
- **On-disk layout as built:** the run is `k = overflow_pages(page_size, 16 × n)` contiguous pages. Page 1 of the run starts with `Page_Header{pgno = run, flags = PAGE_FREELIST, overflow_count = k}`. The `n` records follow from offset 16 across the pages, in `(txn_id, pgno)` order, and the tail is zeroed. The records are the `ready` pages (tag 0, ascending), then `pending` unchanged, then this commit's `freed` pages plus the previous run's pages, tagged `S + 1`. Each group is sorted and the tags increase, so concatenating them gives a sorted list. The meta page stores `freelist_pgno = run` and `freelist_count = n`, or `0`/`0` with no run when `n = 0`.
- `kv/overflow.odin`: `overflow_check`'s header test is now `run_header_check(first, pgno, last, flags, size)`, which takes the expected flag. `overflow_check` and `freelist_run` both use it.
- `kv/env.odin`:
  - `Snapshot` gains `freelist_pgno` and `freelist_count`.
  - `Env.free` is owned by the writer.
  - `env_open` calls `freelist_load` after `meta_choose`, and the deferred cleanup frees the list on any later failure. `env_close` frees it.
  - `meta_read` also rejects a meta page whose run doesn't lie within `[2, last_pgno]`. It first bounds `count ≤ file bytes / 16`, so the size computation can't overflow.
- `kv/commit.odin`: `txn_commit` builds the next state, allocates the run through `page_alloc` (which extends the file, so its `Map_Full` is the commit's), and writes the run with the dirty pages in page order. It sets the meta fields. After the meta sync and the snapshot publish, it swaps `Env.free` while the transaction still holds `writer_mutex`. The doc comment's steps are updated.
- `kv/check.odin`: `space_check(txn, allocator) -> (ok, reason)`.
  - It shares `tree_walk` with `tree_check`, then marks the run's pages and every record's page.
  - In a write transaction it also marks `freed` and `loose`.
  - It requires the number of marked pages to equal `last_pgno − 1`. Every mark is range-checked and refuses duplicates, so this means every page is owned exactly once.
  - Reasons: `page owned twice`, `page owned by nothing`, `free page out of range`, `bad free-list run`.
- `kv/txn.odin`: the `freed`/`loose` comments now describe what commit does with them.

**Tests** (92 in total, 9 of them new in `tests/freelist_test.odin`)
- `test_freelist_round_trip`: 60 commits of random puts (some with overflow values), with a loose run every third commit. The test keeps its own expected list: loose pages as ready, and `freed` plus the previous run tagged with the new `txn_id`. After every commit it compares that list with `Env.free` and with the run read straight from the file (`os_pread`, with the header checked), then runs `space_check` in the write transaction and in a new reader. Every 20 commits it reopens the database and checks that the run on disk is unchanged, that records tagged below `S` moved to `ready` and only tag `S` stays pending, and `space_check` again.
- `test_freelist_empty_list_writes_no_run`: the first commit writes `0`/`0`. The second commit's run is its last page, and its count equals `len(freed)`.
- `test_freelist_opens_file_without_list`: a `build_tree_file` database (both fields 0) opens with an empty list and passes `space_check`. Its first commit records the replaced path tagged 2.
- `test_freelist_io_error_leaves_free_unchanged`: `Env.free` (both arrays) and the snapshot are unchanged after a failed commit. The next commit extends that same list, and the database reopens cleanly.
- `test_freelist_run_map_full`: after a put, the test takes every page left in the map with `page_alloc`. Commit returns `Map_Full`, and the snapshot, `Env.free` and the writer lock are as before. Reopening gives the last commit, and `space_check` passes.
- `test_space_check_catches_leak_and_double`: dropping a `freed` page gives "owned by nothing". Adding the root to `freed`, or a free-list page to `loose`, gives "owned twice".
- `test_freelist_load_valid`: a hand-written list at txn 5. Pages 3, 4, 9 and 12 (tags 0, 2 and 4) are ready; pages 5 and 8 (tag 5) are pending.
- `test_freelist_load_rejects_bad_lists`: 16 hand-edited runs, each returning `Corrupted`. Every case has a valid older meta page (txn 4), which proves there is no fallback. The cases:
  - tag after the snapshot;
  - tags out of order; pages out of order;
  - the same record twice;
  - a page reusable twice; a page both reusable and pending;
  - a page inside the run;
  - pages past `last_pgno`, on a meta page, and page 0;
  - header flags; header page number; header page count;
  - a count that needs more pages than the header says;
  - a count with no run; a run with no records.
- `test_freelist_run_out_of_range_invalidates_meta`: a run on a meta page, past `last_pgno`, ending past `last_pgno`, or with a count larger than the file makes `meta_read` reject that meta page. The database opens at txn 4 with an empty list.
- `space_check` was added:
  - in `run_model`, on the write transaction before every commit or abort, and on a new reader after every commit, abort and reopen;
  - in `commit_test`'s multi-commit tests: `and_reopen`, `alternate_meta_pages` (after each of 100 commits), `falls_back_when_newest_meta_damaged`, `map_full_then_abort`, `io_error_rolls_back`, `replaces_committed_overflow` (write transaction and reader), and `snapshot_isolation` (old and new reader).

**Decisions and deviations**
- **The next free state is built with `env.allocator`, not in the arena and copied afterwards.** Its capacity is reserved before any page is written. After the meta sync the swap can't fail, so `Env.free` never disagrees with a durable commit. `Out_Of_Memory` while building aborts the commit before any I/O.
- **In a write transaction, `space_check` reads the begin snapshot's list from the run on disk** rather than from `Env.free`, plus `freed`/`loose`. Nothing is taken from `ready` in this task, so "pages taken but not yet used" has nothing to mark. **KV-T-0012 must extend `space_check`:** pages taken from `ready` are listed on disk and also owned by the tree, a loose list or the new run, so they must not be marked twice.
- **A run with `freelist_count = 0` and `freelist_pgno ≠ 0` is `Corrupted`.** The design only specified the converse, but commit never writes this shape.
- **Run placement is checked in `meta_read`, so it causes a fallback; the records are checked in `freelist_load`, which returns `Corrupted`.** This follows the task's split. `freelist_run` checks the placement again, so it stands on its own for `space_check`.
- **Duplicate detection** sorts `ready`, compares neighbours, and binary-searches each pending page in `ready`. This is equivalent to the design's "checked while merging into `ready`". Within a tag, strict ordering already rules out duplicates.
- **`Tree_Checker.visited` is now a bitset** (one bit per page up to `last_pgno`) with a marked count, where it was a map. `space_check` shares it, and it keeps the extra checks in the 100 k-op model test cheap. `tree_check`'s behaviour and reasons are unchanged.
- **`run_model` treats `Map_Full` from `txn_commit` like a put's `Map_Full` when `stop_on_map_full` is set** (D6: commit can now fail on the run). A sweep of 16 seeds never hit it, because a put's up-front reserve exceeds the run. `test_freelist_run_map_full` covers the path directly.
- **`freelist_build` sorts `w.loose` in place.** The transaction is ending either way.

**Verification:** `scripts/test.sh` passes. 92/92 in debug (18.2 s), `-o:speed` (8.3 s) and `-sanitize:address` (30.2 s), plus `odin check` for darwin/linux × arm64/amd64. Before this task the debug run took 13.6 s; the difference is mostly the extra checks in the model test.

**Deliberate-bug checks.** For each check the source was backed up to the scratchpad and restored from there, then confirmed identical with `cmp`. Leftover temp dirs from runs that bailed out were removed.
1. *Drop the previous run from the new list* (`run_pages = 0` in `freelist_build`): `space_check` fails with "page owned by nothing" in the model test, `alternate_meta_pages` and `io_error_leaves_free_unchanged`, and the round trip reports differing pending records.
2. *Skip one freed page* (drop the first after sorting): `space_check` fails with "owned by nothing" in 7 commit and free-list tests and in the model test, and `empty_list_writes_no_run` sees count 0.
3. *Tags:*
   - Freed pages tagged `S + 2`: every reopen returns `Corrupted` (9 tests fail), and the round trip and `opens_file_without_list` see the wrong tag.
   - Swapping the tags of the first and last record in `freelist_write`: every reopen returns `Corrupted` (5 tests), and the round trip sees the run differ.
   - Removing the `tag > S` check at open: `rejects_bad_lists` fails on "tag after the snapshot".
4. *No duplicate check among ready pages* fails "page reusable twice". *No ready/pending duplicate check* fails "page reusable and pending".
5. *No inside-the-run check* fails "page inside the run".
6. *`Env.free` swapped before the writes instead of after the meta sync*: `io_error_leaves_free_unchanged` fails on "pending records changed", then "owned twice", then `Corrupted` on reopen. `run_map_full` doesn't catch this one, because its failure comes before the swap point.
7. *No run range check in `meta_read`*: `run_out_of_range_invalidates_meta` fails, returning `Corrupted` instead of falling back.
8. *Tag-`S` records made reusable at open* (`<=` for `<`): `load_valid` and the round trip's reopen check fail.
