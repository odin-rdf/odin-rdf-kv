# Make fuzz seeds reach spills and depth 5

## Objective

Found by KV-T-0031 (2026-09-25) in the fuzz mode's stats:
- Seeds with 100 keys and the smallest pool never spill, because the whole tree fits in the pool.
- Trees reach depth 4 at both 3,000 and 10,000 keys, so the larger key count costs twice the time and reaches no new depth.

## Acceptance Criteria

- [ ] Tie the key count to the pool, so every smallest-pool seed spills (`Model_Stats.spills > 0`).
- [ ] Add a key-space shape with mostly long keys, used by some seeds, so they reach depth 5 (`Model_Stats.max_depth`), and drop or shrink the 10,000-key choice if it adds nothing.
- [ ] Seed-to-options stays a function of the seed alone, so one seed still reproduces alone.
