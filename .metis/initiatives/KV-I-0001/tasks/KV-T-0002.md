# Environment open/close with meta page selection

## Parent Initiative

[[KV-I-0001]]

## Objective

Implement `env_open` and `env_close`. They create a new database file with two initial meta pages, or open an existing one: reserve the read-only map, choose the valid meta page with the highest `txn_id`, and publish it as the environment's current snapshot.

## Acceptance Criteria

- [ ] `env_open(path, options) -> (^Env, Error)` takes `Options { map_size, page_size }`. `page_size` is used only when creating a new file.
- [ ] **New or empty file:** write meta page 0 and meta page 1 (both `txn_id = 0`, `root = 0`, `depth = 0`, `last_pgno = 1`, `entries = 0`), then sync.
- [ ] **Existing file:**
  - Validate magic, version, page size and checksum for each meta page, and use the valid one with the higher `txn_id`. On a tie, use page 0.
  - A meta page whose `last_pgno` lies beyond the file size counts as invalid.
- [ ] If both meta pages are invalid, return `Corrupted`. If the file is locked by another handle, return `Locked`. Any I/O failure returns `Io`.
- [ ] **`Env` holds:** fd, map base, `map_size`, `page_size`, the current snapshot (`txn_id`, `root`, `depth`, `last_pgno`, `entries`), the snapshot mutex and the writer mutex.
- [ ] `os_advise_random` is applied to the map.
- [ ] `env_close` unmaps, unlocks and closes. It is safe to call once all transactions have ended; in debug builds, assert that none are active.
- [ ] **Tests:**
  - create, close and reopen round-trips the snapshot;
  - corrupting meta page 0's checksum falls back to meta page 1, and the reverse;
  - corrupting both returns `Corrupted`;
  - bad magic returns `Corrupted`;
  - a second `env_open` on the same path returns `Locked`;
  - the highest `txn_id` wins (craft the two meta pages by hand with different `txn_id`s).

## Implementation Notes

### Technical Approach
- **Reserve first, then read:** reserve the map *before* reading the meta pages. This lets them be read through the map, with no `pread` buffers.
- **Page size of the second meta page:** its offset depends on the page size. If meta page 0 is valid, use its page size. Otherwise, try each valid page size (4, 8, 16 and 32 KiB) for page 1.
- **Reading meta safely:** copy each meta page into a local `Meta` value before validating it, so a concurrent writer (not possible yet, but it will be) cannot change it mid-check.
- **Test helper:** keep a `meta_write(env, slot, meta)` helper for the tests; T7 reuses it for commit.

### Dependencies
- KV-T-0001 (types, structs, platform layer).

### Risk Considerations
- **Reading past the end of the file** through the map raises `SIGBUS`. Check the file size before touching page 1, and before trusting `last_pgno`.
