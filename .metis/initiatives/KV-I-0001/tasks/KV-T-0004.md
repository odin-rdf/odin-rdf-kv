# Read path: read transactions, page_ptr and get

## Parent Initiative

[[KV-I-0001]]

## Objective

Implement read transactions and zero-copy lookups: `txn_begin` for read-only transactions, `txn_abort`, the single `page_ptr` access path, tree search from the snapshot root, and `get` returning a slice into the map.

## Acceptance Criteria

- [x] **`Txn` fields:** env pointer, read-only flag, the snapshot (`txn_id`, `root`, `depth`, `last_pgno`, `entries`) and a generation counter. Placeholders for write-transaction state are filled in by KV-T-0005.
- [x] **`txn_begin(env, read_only = true) -> (Txn, Error)`:** copies the snapshot under the snapshot mutex. No reader table yet, but the procedure keeps the shape that step 5 needs.
- [x] **`txn_abort(^Txn)`:** ends the transaction, bumps its generation, and is idempotent.
- [x] **`page_ptr(txn, pgno) -> []byte`** is the only way to reach a page:
  - it returns `map_base[pgno*ps : (pgno+1)*ps]`;
  - in debug builds it asserts `pgno ≤ last_pgno`;
  - it has a hook point (a comment or empty proc) for step 6's chunk accounting.
- [x] **Tree search:** `tree_search(txn, key, path: ^Path) -> (leaf_idx, exact, Error)` descends from `root`. It records `(pgno, idx)` at each level in a fixed-size `Path` stack (`MAX_DEPTH = 24`), which KV-T-0005 and KV-T-0008 reuse.
- [x] **`get(txn, key) -> ([]byte, Error)`:**
  - returns a slice into the map for inline values, or `Not_Found`;
  - `BIGDATA` values return `Corrupted` until KV-T-0006 lands;
  - an empty tree (`root = 0`) returns `Not_Found`.
- [x] **Tests:**
  - a test helper `build_tree_file(path, entries)` builds a two-level tree by hand with the KV-T-0003 page layer and writes a valid meta page;
  - `get` finds every key and misses absent ones, including keys before the first and after the last;
  - returned slices point inside the map range;
  - `get` performs zero allocations (checked with a `mem.Tracking_Allocator` as `context.allocator`).

## Implementation Notes

### Technical Approach
- **Descending:** at each branch, use `branch_find_child`. Depth is checked against the snapshot's `depth`, and a mismatch or a page with the wrong flags returns `Corrupted`.
- **Test helper:** keep `build_tree_file` in `tests/helpers.odin`. It is also useful for fuzzing format edge cases later.

### Dependencies
- KV-T-0002 (env and snapshot) and KV-T-0003 (page layer).

### Risk Considerations
- **Slice lifetime:** a slice must not outlive its transaction. There is nothing to enforce yet beyond documentation and the generation counter, which the debug checks in KV-T-0008 build on.

### 2026-09-24: completed
- **Files:** `kv/txn.odin` (`Txn`, `txn_begin`, `txn_abort`, `page_ptr`) and `kv/tree.odin` (`MAX_DEPTH`, `Path`, `tree_search`, `get`), both new; `kv/env.odin` now reads `active_txns` atomically.
- **Tests:** `tests/tree_helpers.odin` and `tests/read_test.odin`, 7 new tests.
- **Verification:**
  - All 39 tests pass with `-debug`, `-o:speed` and `-debug -sanitize:address` on macOS arm64; `kv` and `tests` type-check for `linux_arm64`, `linux_amd64` and `darwin_amd64`.
  - Removing the page-header check makes the corruption test fail. Removing the child bounds check makes the test process die with SIGBUS (exit 138), because the bad child points far past the end of the file.
- **API as built:**
  - `txn_begin(env, read_only := true) -> (Txn, Error)`. `Txn` is a value that must not be copied while in use; the idiom is `defer txn_abort(&txn)`. For now `txn_begin` asserts `read_only`; KV-T-0005 lifts that.
  - `txn_abort(^Txn)` is idempotent and safe on a zero-value `Txn`, for example after a failed begin. It sets `done`, bumps `gen`, and decrements `env.active_txns` atomically.
  - `page_ptr(^Txn, Pgno) -> []byte`. Debug builds assert that the transaction hasn't ended and that `pgno ≤ snapshot.last_pgno`. It has a comment marking the step 6 accounting hook.
  - `tree_search(txn, key, ^Path) -> (exact, Error)`:
    - the leaf slot is `path_leaf(&path).idx`, the first key ≥ `key`;
    - an empty tree gives `path.depth == 0`;
    - `Path_Entry.idx` is an `int`, not the `u16` the initiative sketched.
  - `get(txn, key) -> ([]byte, Error)`. An overflow (`BIGDATA`) value returns `Corrupted` until KV-T-0006.
- **Corruption checks while descending:**
  - each page's header `pgno` must match the pointer followed;
  - the page kind must match its level (branch above the last level, leaf at it);
  - `lower` and `upper` must be sane;
  - branch pages must be non-empty;
  - child page numbers must be in `[2, last_pgno]`;
  - `depth > MAX_DEPTH` is `Corrupted`.
- **Why the child bounds check matters:** it runs before `page_ptr`. Without it, a child beyond the end of the file but inside the map causes a SIGBUS crash rather than an error.
  - A child only *just* past the end may still read as zeros, because OS pages on Apple Silicon are 16 KiB and the file's last OS page is partly beyond EOF. Such a page then fails the header check. Checks on the file's extent must therefore not rely on SIGBUS happening.
- **Test helpers for later tasks** (in `tests/tree_helpers.odin`):
  - `build_tree_file(t, path, entries, options, txn_id)` builds a tree of any depth bottom-up from sorted entries with inline values, then writes its pages and a meta page;
  - `even_entries(n)` makes 8-byte big-endian keys 0, 2, 4, … with values "v<i>";
  - `u64_key`;
  - `read_page` and `write_page(env, pgno, page)`. `write_page` takes an explicit page number because a test that alters the header's page number would otherwise write to the wrong place (a bug found while writing these tests).
