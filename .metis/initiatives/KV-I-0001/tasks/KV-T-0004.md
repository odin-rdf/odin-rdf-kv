# Read path: read transactions, page_ptr and get

## Parent Initiative

[[KV-I-0001]]

## Objective

Implement read transactions and zero-copy lookups: `txn_begin` for read-only transactions, `txn_abort`, the single `page_ptr` access path, tree search from the snapshot root, and `get` returning a slice into the map.

## Acceptance Criteria

- [ ] **`Txn` fields:** env pointer, read-only flag, the snapshot (`txn_id`, `root`, `depth`, `last_pgno`, `entries`) and a generation counter. Placeholders for write-transaction state are filled in by KV-T-0005.
- [ ] **`txn_begin(env, read_only = true) -> (Txn, Error)`:** copies the snapshot under the snapshot mutex. No reader table yet, but the procedure keeps the shape that step 5 needs.
- [ ] **`txn_abort(^Txn)`:** ends the transaction, bumps its generation, and is idempotent.
- [ ] **`page_ptr(txn, pgno) -> []byte`** is the only way to reach a page:
  - it returns `map_base[pgno*ps : (pgno+1)*ps]`;
  - in debug builds it asserts `pgno ≤ last_pgno`;
  - it has a hook point (a comment or empty proc) for step 6's chunk accounting.
- [ ] **Tree search:** `tree_search(txn, key, path: ^Path) -> (leaf_idx, exact, Error)` descends from `root`. It records `(pgno, idx)` at each level in a fixed-size `Path` stack (`MAX_DEPTH = 24`), which KV-T-0005 and KV-T-0008 reuse.
- [ ] **`get(txn, key) -> ([]byte, Error)`:**
  - returns a slice into the map for inline values, or `Not_Found`;
  - `BIGDATA` values return `Corrupted` until KV-T-0006 lands;
  - an empty tree (`root = 0`) returns `Not_Found`.
- [ ] **Tests:**
  - a test helper `build_tree_file(path, entries)` builds a two-level tree by hand with the KV-T-0003 page layer and writes a valid meta page;
  - `get` finds every key and misses absent ones, including keys before the first and after the last;
  - returned slices point inside the map range;
  - `get` performs zero allocations (checked with a `mem.Tracking_Allocator` as `context.allocator`).

## Implementation Notes

### Technical Approach
- **Descending:** at each branch, use `branch_find_child`. Depth is checked against the snapshot's `depth`, and a mismatch or a page with the wrong flags returns `Corrupted`.
- **Test helper:** keep `build_tree_file` in `tests/helpers.odin`. It is also useful for fuzzing format edge cases later.

### Dependencies
- KV-T-0002 (env and snapshot) and KV-T-0003 (page layer).

### Risk Considerations
- **Slice lifetime:** a slice must not outlive its transaction. There is nothing to enforce yet beyond documentation and the generation counter, which the debug checks in KV-T-0008 build on.
