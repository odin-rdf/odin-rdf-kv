# del: removal, rebalancing and root collapse

## Parent Initiative

[[KV-I-0003]]

## Objective

Implement `del(txn, key) -> Error` as designed in KV-I-0003 (REQ-001 to REQ-008, D1 to D8): search, check `Map_Full`, touch the path, remove the node and its overflow run, rebalance upwards, collapse the root.

## Acceptance Criteria

- [ ] `del` exists with a contract comment covering the lifetime rules (REQ-007, REQ-008), `Map_Full` at a full map, and the two iteration patterns (delete everything with `cursor_first`, delete a range by copy + `del` + `cursor_seek`).
- [ ] REQ-001: a missing key returns `Not_Found` with no page touched, `txn.mods` unchanged, `txn.err` unset.
- [ ] REQ-002: `Txn_Read_Only`; an earlier `txn.err` is returned; a failure after changes starts sets `txn.err`.
- [ ] REQ-003: an overflow value's run is freed, to `loose` if this transaction wrote it, else to `freed`.
- [ ] REQ-004/D4/D5: the rebalance loop from the leaf to level 1: drop an empty page (making the parent's slot 0 −∞ when needed), else stop unless underfull, else merge with the right sibling, then the left, if they fit; stop at the first level with no change.
- [ ] REQ-005: a root branch with one child collapses (repeatedly); deleting the last key gives `root = 0`, `depth = 0`, `entries = 0`; `entries` drops by one per delete.
- [ ] REQ-006/D2: `Map_Full` up front unless `depth` single pages are available; merges allocate no page.
- [ ] Shape tests in a new `tests/delete_test.odin`, on committed trees from `build_tree_file`, with `tree_check` and `space_check` after each commit:
  - delete leaving the leaf above the threshold;
  - merge with the right sibling; with the left sibling (rightmost child);
  - underfull page whose siblings are too full (no merge);
  - branch merge with the separator brought down;
  - empty leaf under a single-child parent (cascade);
  - cascade to a root collapse, and collapse over several single-child levels;
  - delete the last key;
  - an overflow value from a committed tree and one written in the same transaction.
- [ ] Semantics tests: `Not_Found` changes nothing and a cursor stays valid; `Txn_Read_Only`; `Map_Full` at a full map with no free pages and success with some; deleting a key obtained from `get` and from a cursor in the same transaction; delete-everything through `cursor_first`; abort after deletes leaves the database and `Env.free` unchanged; reopen after deletes.
- [ ] Deliberate-bug checks, each failing a test (record which): forget to free the merged sibling; no separator brought down; skip clearing slot 0; skip dropping an empty page without a sibling; forget `entries -= 1`; skip freeing the overflow run; touch the path before the search on a miss.
- [ ] `scripts/test.sh` passes.

## Implementation Notes

### Technical Approach
- Mirror `put`: a public `del` with the checks, and a private `del_unchecked` whose error is stored in `txn.err`.
- The path from `tree_search` already has the parent slot index at every level, so a sibling is `branch_child(parent, idx ± 1)`. After merging with a left sibling, point the left slot at the path page and remove the path page's slot; after a right sibling, remove the right slot.
- Keep a stack buffer (`MAX_KEY_SIZE_ANY`) for the separator, copied from the parent before the parent changes.
- The sibling is read through `page_ptr` (committed or dirty) and freed with `page_free`; it is never touched.
- Decide here whether `del` goes in `write.odin` or a new `delete.odin`, and update the code map in `CLAUDE.md`.

### Dependencies
KV-T-0016 (merge primitives, `page_free`).

### Risk Considerations
- A sibling that is dirty must go to `loose`, not `freed`, or `space_check` finds it owned twice.
- Collapsing the root frees a dirty page (the root was touched), so it goes to `loose`.
- An empty root leaf must become `root = 0`; `put` already handles an empty tree by allocating a new root.
