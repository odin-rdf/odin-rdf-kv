# Chunk accounting for mapped pages

## Parent Initiative

[[KV-I-0004]]

## Objective

Keep the store's own estimate of how much of the map is resident, in chunks, on every page access (KV-I-0004 D7, D11). No eviction yet: this task makes the estimate exist and cheap, and reports it.

## Acceptance Criteria

- [ ] `Options.chunk_size`: 0 means 256 KiB; otherwise a power of two, at least 64 KiB and at least the page size, else `Invalid_Argument`. `map_size` is rounded up to whole chunks.
- [ ] `Options.mapped_budget` in bytes, 0 meaning no budget (accounting on, no eviction). Stored for KV-T-0023.
- [ ] A chunk table of one byte per chunk with two bits, `resident` and `referenced`, updated atomically, and an atomic `resident_chunks`.
- [ ] `page_ptr` for a page read from the map: an atomic load of the chunk's byte; set `referenced` if clear; if `resident` is clear, set it with a CAS and, if this thread won, increment `resident_chunks` and call an out-of-line hook (the watermark check in KV-T-0023; a no-op here). Dirty-page reads don't count.
- [ ] `overflow_value` marks every chunk of the run. `freelist_load` marks the chunks it read.
- [ ] `Stats` gains `mapped_budget`, `chunk_size`, `resident_chunks` and `chunk_faults` (cumulative chunk transitions to resident), plus `free_list_bytes` (the RAM `Env.free` holds).
- [ ] Tests: reads crossing a chunk boundary mark both chunks once; an overflow value spanning chunks marks them all; concurrent readers on the same chunk count it once (threads, TSan); `chunk_faults` equals `resident_chunks` before any eviction; option validation.
- [ ] **Read throughput with accounting on and off** (a define that compiles it out, for the measurement only), on the existing read benchmarks, recorded here (NFR-002: target under 5%).
- [ ] Deliberate-bug check: increment the count without the CAS (plain store), and the concurrent test fails under TSan or by count. Record it here.
- [ ] `scripts/test.sh` passes.

## Implementation Notes

### Technical Approach
- `page_ptr` is `#force_inline`; keep the fast path (bits already set) to a shift and one atomic load, and put everything else out of line.
- Avoid writing the byte when `referenced` is already set, so hot chunks shared between reader threads don't bounce a cache line.
- The chunk table's size is `map_size / chunk_size` bytes: 4 KiB for the default 1 GiB map at 256 KiB.

### Dependencies
None in code; it can be built before or after the spilling tasks. KV-T-0023 builds on it.

### Risk Considerations
- Pages faulted in through a held slice after an eviction aren't seen (a known limit, KV-I-0004 Q4); nothing to do here.
