# Recreate a new file with nothing written

## Parent Initiative

[[KV-I-0005]]

## Objective

A crash while creating a database must not leave a file that can never be opened (KV-I-0005 D6), and the sweep must cover creation (workload 5).

## Acceptance Criteria

- [ ] `env_open`: when `meta_choose` finds no valid meta page, the file is exactly `2 × page_size` (the page size this open would use) and every byte of it is zero, initialise it as a new database. Anything else without a valid meta page stays `.Corrupted`.
- [ ] The doc comment of `env_open` states the rule.
- [ ] Workload 5 of the design, `env_open` of a new path, swept with kill and power-loss images: each opens as an empty database, or with one valid meta page, never `.Corrupted`.
- [ ] Tests: a 2-page zero file opens as empty and takes a commit; a 2-page file with one nonzero byte, a 3-page zero file and a zero file at another page size return `.Corrupted`.
- [ ] Deliberate-bug checks recorded: accept any all-zero file regardless of size (the 3-page test fails); remove the rule (the workload 5 sweep fails).
- [ ] `scripts/test.sh` and `scripts/test-linux.sh arm64` pass.

## Implementation Notes

### Dependencies
KV-T-0027 and KV-T-0028 (the sweep and the power-loss images).
